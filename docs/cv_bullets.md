# CV-ready project bullets

**AI Data Quality Detective | Python, Pandas, SQL, Statistics, Streamlit, Scikit-learn**

- Built an automated data-quality investigation platform detecting missing values, duplicates, invalid/domain violations, category inconsistencies, date anomalies, outliers, schema/contract violations, and distribution shifts across CSV, Excel, and SQLite data sources.
- Designed a transparent five-dimension Data Quality Scorecard and PASS/WARNING/FAIL quality gate, with record-level evidence, severity prioritization, investigation recommendations, and historical batch monitoring.
- Combined SQL quality checks, statistical tests (IQR, Z-score, KS, chi-square, PSI), and Isolation Forest anomaly detection in a Streamlit dashboard with GitHub Actions CI and exportable investigation reports.
