# AI Data Quality Detective: Portfolio Summary

## Elevator pitch

A production-inspired data-quality investigation platform that turns messy analytical inputs into a prioritized, evidence-backed quality report and historical monitoring signal.

## Stack

Python, Pandas, NumPy, SciPy, Scikit-learn, SQLAlchemy, SQLite, Streamlit, PyYAML, GitHub Actions

## Core strengths demonstrated

- Exploratory data profiling
- Data validation and business rules
- Statistical reasoning
- Unsupervised anomaly detection
- SQL quality analysis
- Data contracts
- Quality gates
- Monitoring and regression tracking
- Dashboarding and reporting
- Automated testing

## Demo headline

**5,012 rows → 24 findings → 8 Critical/High → 85.09/100 → FAIL gate → investigation report**
